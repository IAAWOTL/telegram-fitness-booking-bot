# Telegram-бот для записи на персональные тренировки

Учебный проект, выполненный в рамках курса «Основы Python. Часть 1» в Skillbox.
Этот курс входит в программу «Профессия Python-разработчик», которую я сейчас прохожу.

## О проекте

Бот помогает пользователю оставить заявку на персональную тренировку через Telegram.
Пользователь выбирает вид тренировки, вводит номер телефона, дату и время занятия.

После оформления заявки бот:

- отправляет пользователю подтверждение;
- отправляет администратору уведомление о новой записи;
- отправляет пользователю сообщение с памяткой;
- отправляет изображение с памяткой о подготовке к тренировке.

Проект выполнен на базе стартового кода учебного бота. В ходе работы были доработаны сценарий записи, проверка пустого ввода, очистка данных заявки и отправка изображения.

## История проекта

Изначально в курсе был предоставлен стартовый код Telegram-бота для записи на персональные тренировки.

В рамках финальной работы я доработал проект:

- добавил очистку незавершённых данных пользователя при команде `/start`;
- добавил проверку пустого номера телефона;
- добавил проверку пустой даты и времени;
- добавил подтверждение обработки нажатия inline-кнопки;
- добавил очистку данных после успешной записи;
- перенёс настройки бота в файл `.env`;
- настроил отправку изображения с памяткой из локальной папки.

В результате бот позволяет выбрать тренировку, указать номер телефона, дату и время, отправляет подтверждение пользователю, уведомляет администратора и отправляет пользователю памятку о подготовке к тренировке.

## Пользовательский сценарий

1. Пользователь отправляет `/start`.
2. Бот показывает список тренировок с ценами.
3. Пользователь выбирает тренировку через inline-кнопку.
4. Бот запрашивает номер телефона.
5. Бот запрашивает дату и время занятия.
6. Пользователь получает подтверждение записи.
7. Администратор получает уведомление.
8. Пользователь получает памятку.

## Запуск

1. Установить зависимости из `requirements.txt`.
2. Создать файл `.env` на основе `.env.example`.
3. Указать в `.env` токен бота и Telegram ID администратора.
4. Убедиться, что файл `assets/pamyatka.jpg` находится на месте.
5. Запустить `fitness_bot.py`.

Файл `.env` не добавляется в репозиторий.

## Ограничения текущей версии

Это учебная демонстрация, а не готовая коммерческая система.

- данные текущей заявки хранятся в памяти программы;
- после перезапуска бота данные очищаются;
- не реализована проверка свободного времени;
- не подключена база данных;
- проверка телефона и даты является базовой.
